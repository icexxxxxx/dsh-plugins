# Icex DSH Fixer

一个本地 DSH Web 插件，用来做几处会话界面上的调整。

## 功能

**1. 输入锚点导航**

- 在会话内容区左侧显示一列竖向圆点，每个轮次一个圆点；正常会话里每个轮次由一条用户输入开启。
- 悬停圆点默认 1 秒后显示该条输入的内容；悬停延迟可在设置里调整（200 到 3000 ms）。
- 点击圆点平滑滚动到对应输入；如果该轮对话还没加载，会先加载历史再定位。
- 当前阅读位置对应的圆点会加深显示；加载历史时圆点会闪烁。
- 可选隐藏 DSH 自带的右侧轮次导航，避免左右两套导航重复。

**2. 双击右 Option 唤起窗口**

- 默认行为：在系统的任意位置快速双击键盘右侧 Option（350ms 内两次），切到 DSH 窗口并把它摆到窗口所在屏幕的顶部。
- 宽度占满该屏幕，高度保持当前高度（超出可用高度时自动收窄），并置顶聚焦。
- 如果窗口在另一个桌面/显示器：helper 会切过去，然后在那边置顶/定位；不会把窗口搬到当前桌面（SIP 限制）。如需跟随每个桌面，可在 Dock 右键 DSH → 选项 → 分配到 → “所有桌面”，代价是窗口打开时每个桌面都可见。
- 需要系统辅助功能（Accessibility）和输入监控权限；helper 只监听右侧 Option，不记录其他键盘，不联网。
- helper 日志：/tmp/icex-dsh-fixer-summon-<uid>.log；源码在 native/summon.swift，重新编译运行 native/build.sh。

**3. 纯净模式（关闭全部插件）**

- 在插件详情页的「纯净模式」里打开开关：确认框会给出这次要关闭的插件数量，只保留 `@deepseek-ai/dsh-base`、`@deepseek-ai/dsh-web-app` 和本插件。
- 关闭前先把当前启用的插件名单写到 `~/.dsh/fixer/bare-mode.json`（按 profile 分开，同时留一份 `.bak`），写成功后才开始逐个关闭；中途失败、刷新或重启都不会让已关闭的插件失去记录。
- 本插件保持加载（否则开关本身会消失），但会隐藏自己的界面改动：左侧圆点、会话菜单的「删除会话」、以及对原生右侧导航的隐藏。聊天区看起来就是 DSH 原貌；纯净模式期间上面的锚点设置会置灰，避免看起来“开关坏了”。
- 恢复：同一个开关拨回来，按快照顺序重新启用。想手动恢复也行：插件页里每个插件仍然可以单独打开。
- 个别插件如果被别的插件依赖、暂时关不掉，会列在开关下方的红框里，其余插件照常关闭；刷新页面后生效。
- 别在插件列表里停用本插件：那样会连一键恢复入口一起消失。插件页里重新启用它就能找回恢复开关，快照还在。
- 兜底（按顺序）：① 插件页里逐个打开插件；② 页面还能打开时，在 Console 里执行 `fetch('/api/icex-fixer/bare-mode', { method: 'POST', headers: { 'content-type': 'application/json' }, body: '{"action":"off"}' })`（与页面共用登录态，命令行 curl 会 401）；③ 页面打不开时，退出 DSH，把快照里的名单写回 `~/.dsh/profiles/<profile>/package.json` 的 `dsh.profile.bundles` 再重启——依赖没有被卸载，不需要重装。
- 快照和备份都丢失时不会自动恢复：关闭动作本身不写别处，只能按 ③ 手工恢复。

**4. 删除会话**

- 会话行的「…」菜单里有一项「删除会话」；确认后 Host 把该会话的日志目录移到 `~/.dsh/trash/sessions/`，列表里立刻移除。
- 正在打开的会话会被拒绝，提示先切到别的会话。
- 只移动日志，不彻底删除；要彻底清掉去回收站目录手动删。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 显示锚点导航 | 开启 | 关闭后不注册左侧圆点，也不隐藏原生导航 |
| 悬停提示延迟 | 1000 ms | 悬停多久后显示输入内容 |
| 隐藏原生右侧轮次导航 | 开启 | 仅在本插件导航开启时生效 |
| 双击右 Option 唤起 | 开启 | macOS 原生 helper；切到 DSH 窗口所在桌面并置顶定位；可选 All Desktops |
| 纯净模式 | 关闭 | 关闭除 DSH 内核和本插件外的所有插件层；状态保存在 Host |

锚点和悬停延迟保存在当前浏览器的 localStorage；唤起功能由 Host 半启动的原生 helper 提供，默认开启，不需要额外保存设置。纯净模式的状态保存在 profile 的 Host 上（`~/.dsh/fixer/bare-mode.json`），刷新或重启后仍然有效。

## 使用

1. 在 **Plugins** 里安装本地目录，然后启用 **icex-dsh-fixer**。
2. 打开任意一个已有对话，左侧应出现圆点导航；在插件详情页调整悬停延迟。
3. 刷新页面后设置仍在。

## 已知边界

- 锚点以“轮次”为单位：每条开启新轮次的用户输入对应一个圆点；轮次进行中的插话（steering）不单独成点；没有文本输入的特殊轮次也会有一个圆点，提示里显示轮次号。
- 已加载的轮次在悬停时直接读取消息文本；尚未加载的历史轮次使用宿主生成的短预览（约 50 字）。长输入在提示框中会被截断为几行。
- 锚点导航只在 Chat 视图的转录区显示；Trajectory 等其他视图不显示。
- 嵌入式会话（右侧栏中的子代理对话）空间不足时不显示。
- 双击的默认结果是“切到 DSH 窗口所在桌面并摆好”，不是“把窗口搬到当前桌面”。SIP 开启时无法可靠跨 Space/跨显示器搬窗口；All Desktops 可让窗口跟随每个桌面，但会在每个桌面可见。
- 原生 helper 目前是 arm64 macOS 二进制；换机器或换架构需要重新运行 native/build.sh。
