# Icex 插件中心

侧栏里的一个独立页面，用来管理 icex 系列 DSH 插件：安装、更新、启用、停用、移除，以及自动更新。

## 页面能做什么

- 列出 icex 插件及当前版本、运行状态；未安装的显示安装按钮，新版本显示更新按钮。
- 「检查更新」读取 npm 上的最新版本；每个插件可以单独打开「自动更新」。
- 打开全局自动更新后，插件中心会定期检查并静默升级，页脚记录上次检查结果。
- 更新或安装完成后提示是否需要在重启 DSH 后生效。

## 自动更新

默认关闭。打开后按设定间隔（默认 6 小时）检查，只升级声明了 `dsh.bundle` 且与当前 DSH 兼容的版本；失败会记录原因，不会中断其他插件。

## 安装

```sh
dsh plugin --profile desktop add icex-dsh-plugin-center
```
